** issue reportado en versiones específicas de Grype (0.88-0.89) donde db update falla con "invalid cross-device link" cuando la cache está en un volumen Docker. Este caso usa un bind mount (no volumen nombrado) y dir:/work en vez de db update explícito, que es un camino distinto — no debería afectar, pero si ves ese error específico en las pruebas ya sabes que es.

** Anchore cambió la imagen anchore/grype para correr como usuario sin privilegios por defecto (no root) desde hace varias versiones. el contenedor de Grype corre como root únicamente para esta ejecución puntual (--user root), sin afectar nada del resto del sistema — es un contenedor efímero de un solo uso, no un servicio expuesto, así que no hay riesgo real en hacerlo aquí.

** anchore/grype:latest es una imagen distroless (sin sistema operativo real adentro, ni siquiera tiene el archivo /etc/passwd para resolver el nombre "root" a un número). Por eso se usa el número de UID directamente (0), en vez del nombre root — eso no requiere leer /etc/passwd para nada, funciona incluso en imágenes distroless. Este es el patrón exacto como solución oficial reportada por otros usuarios con el mismo problema en el repositorio de Grype.
